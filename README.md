# Topology-Aware OCT-A Retinal Analysis (prototype)
Research prototype: does vessel topology add value over a baseline for disease classification from OCT-A?
See `docs/PROJECT_EXPLANATION_HINGLISH.md`.

Run: `pip install -r requirements.txt && python main.py`
Outputs go to `outputs/` (results.json, confusion matrices, feature importance, pipeline examples).

Status: pipeline works end-to-end on SYNTHETIC data only. Real OCTA-500 not yet used. Not for clinical use.
